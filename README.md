# Digital Shield

Digital Arrest Scam Early-Warning & Threat Analysis System.

## Structure
- `android-app/` — Kotlin consumer app
- `backend/` — FastAPI backend (risk engine, NLP, OSINT, forensics, threat graph)
- `admin-dashboard/` — React investigator platform
- `infra/` — Docker, Postgres, Neo4j, Nginx config
- `docs/` — architecture and reference docs
